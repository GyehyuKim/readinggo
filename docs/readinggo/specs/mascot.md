# 참새 독서 동반자 — 캐릭터 계약

> **결정 (2026-08-25, #1389)**: 브랜드 마스코트와 AI 독서 파트너는 같은 비진화형 2D 참새 캐릭터를 사용한다. 표시명은 #1455 결정 전까지 `Jacky / 재키`를 유지한다.
> **범위**: 이 문서는 캐릭터의 시각 정체성과 검토 산출물만 정의한다. 런타임·자산 변경, Production 승격, 최종 이름 결정은 포함하지 않는다.

## 1. 역할과 적용 표면

- 재키는 기록을 평가하는 보상 장치가 아니라 독서 기록과 대화를 돕는 동반자다.
- 브랜드 마스코트와 AI 독서 파트너는 동일한 얼굴·비율·색·실루엣을 유지한다.
- 현재 활성 표면은 앱 아이콘, 로고, 헤더, 로딩, 로그인, 동반자 대화, 공유 카드, 스토어 자산이다. 새 표면은 별도 제품 결정 없이 추가하지 않는다.
- 사용자 fallback avatar에는 재키를 사용하지 않는다. 사용자 정체성과 동반자 정체성은 형태·레이블·접근성 이름에서 명확히 구분한다.

## 2. 시각 불변조건

- 성인 사용자에게 어울리는 절제된 2D 그래픽이다.
- 전신은 약 2.5등신을 기준으로 하며, 유아형 큰 머리·과장된 눈·짧고 통통한 팔다리를 강조하지 않는다.
- 작은 크기에서도 참새의 실루엣, 부리, 날개가 서로 구분된다.
- 기존 SparrowMark와 함께 쓸 수 있는 sage/green 계열을 정본 색군으로 사용한다. 정확한 토큰은 현행 디자인 시스템에서 선택한다.
- 단계·레벨·성장형 외형 변화가 없다. 보상, 상실, 죄책감, 재촉을 캐릭터 상태로 표현하지 않는다.
- 소품과 배경은 독서 맥락을 보조할 수 있으나 캐릭터의 기본 실루엣과 정체성을 대체하지 않는다.

## 3. 모델 시트 검토 산출물

같은 brief로 일관된 후보 3종을 만든다. 각 후보는 한 장의 모델 시트 안에 다음을 모두 포함한다.

1. 아이콘용 얼굴
2. 전신 정면
3. 전신 측면
4. 기본 감정 4종: 평온, 반가움, 궁금함, 공감
5. 48px 축소 미리보기

후보 간 차이는 선 굵기, 형태 단순화, sage/green 배색 비중처럼 비교 가능한 시각 변수로 제한한다. 후보마다 다른 연령·종·성격으로 보일 정도의 변형은 금지한다.

## 4. 합격 기준

각 후보를 다음 항목별 pass/fail로 기록한다.

- 48px에서 얼굴·부리·날개 또는 얼굴 윤곽이 뭉개지지 않는다.
- 정면과 측면이 같은 캐릭터로 인식된다.
- 네 감정이 과장된 유아형 표정 없이 구분된다.
- SparrowMark와 나란히 놓았을 때 색·형태 계열이 충돌하지 않는다.
- 브랜드 표면과 대화 표면에서 같은 캐릭터로 사용할 수 있다.
- 사용자 fallback avatar와 혼동되지 않는다.
- 진화·보상·상실·죄책감의 의미를 암시하지 않는다.

하나라도 실패하면 해당 후보는 채택하지 않는다. 3종 모두 실패하면 brief를 수정해 다시 비교하며, 가장 덜 실패한 안을 임시 정본으로 승격하지 않는다.

## 5. 검토·출시 게이트

1. 모델 시트 3종을 동일 조건으로 비교한다.
2. stable DEV의 현재 SparrowMark와 활성 표면을 기준으로 크기·대비·정체성 일관성을 먼저 확인한다.
3. 선택 결과와 미해결 항목을 #1389에 연결된 별도 구현·자산 작업의 입력으로 남긴다.
4. 이 문서 변경만으로 자산을 교체하거나 Production에 승격하지 않는다.
5. 이름은 #1455 결정 전까지 `Jacky / 재키`로 유지한다.
