## 0. 책나무 은퇴 뒤 retained 데이터의 개인정보 안전 계약

1. 책나무 제품은 종료한다. 책나무 전용 UI·route·flag·DataStore/RPC·analytics를 mascot이나 실험 명분으로 다시 사용하지 않으며, 남은 DB object는 제거 전 fail-closed inventory다.
2. 문장 본문은 기존 `public|followers|private` 설정과 서버 권한을 따른다. 비공개 문장의 존재·개수·내용과 `my_note`는 retained 피드·프로필·활동함의 비소유자 응답·집계·분석에 포함하지 않는다.
3. 현행 `users`·`user_books`·`wish_books` 등 base table 직접 read는 권한 경계가 아니다. retained surface가 필요한 owner/current-viewer 최소 projection으로 client를 전환하고, 수신·구버전 호출량을 관측해 최소 지원 버전을 승인한 뒤 별도 migration으로 broad base RLS를 축소한다.
4. 역할별 직접 API에서 owner·nonowner·blocked·anonymous와 `private|followers|public`, 유효/무효/타인 private UUID의 존재·개수·오류 차이를 검증한다. rollback에서 broad base SELECT를 복원하거나 책나무 전용 API grant를 되살리지 않는다.
5. XP·둥지·성·하루 만회 전용 데이터는 신규 앱에서 사용하지 않으며 구 APK 호환 목적으로 유지하지 않는다. Production 물리 삭제 전 rollback용 backup의 항목·목적·보유 기간·파기 시점을 migration 승인 기록과 처리방침·데이터 내보내기에 반영한다.
6. 분석 동의 철회 시 향후 이벤트·리플레이 전송 중단뿐 아니라 PostHog identity reset과 기존 이벤트의 삭제 또는 비식별 처리 여부를 결정·검증한다. 현재 처리 범위는 미검증이다.
7. 계정 삭제가 Supabase 데이터만 지우는지, PostHog·문의·모더레이션 감사로그까지 처리하는지와 각 보존기간을 시스템별로 명시한다. 법적 보존과 사용자 삭제의 경계는 승인 전 미결정이다.

### 0.1 내 기록 기반 AI 개인화 안전 계약 (#1309, 목표)

1. **처리 목적과 항목**: 사용자가 요청한 독서 대화에서 현재 문장과 관련된 과거의 본인 저장 문장, 책 제목·저자·쪽수·상태, 자유 감상, 저장 Q/A를 연결하는 데만 쓴다. 공개범위가 `private`인 본인 기록도 선택 동의 뒤 owner 전용 경로에서 사용할 수 있다. 타인 기록은 사용하지 않는다.
2. **별도 동의**: `내 기록을 참고한 대화`는 로그인 계정별 선택 opt-in이며 기본 OFF다. 기존 데이터 활용·분석·리플레이·대화 아카이브 동의, 문장 공개, 서비스 가입에서 동의를 추론하거나 자동 전환하지 않는다. 거부해도 현재 문장·책·해당 대화 history로 제공하는 비개인화 10턴 기능은 유지한다.
3. **최소 처리**: 요청마다 관련 source 최대 5건이며, label·separator와 제목·저자·쪽수·날짜·상태·preview·본문을 포함해 외부 LLM에 전달되는 canonical retrieval context block 전체를 최대 2,000 Unicode 문자로 제한한다. embedding, 사용자 profile/summary, 민감 특성·감정·성격·문체 추론, retrieval 결과·prompt의 복사본/장기 신규 보관은 금지한다. 계정 동의·source 제외와 원문 없는 일시적 dispatch 조정을 위한 최소 제어 metadata만 보관한다.
4. **고지와 권리**: 개인 기록을 실제 사용한 응답에 `참고한 내 기록 N개`와 정확한 source 이동을 제공한다. 사용자는 source별 제외·재포함·기존 기록 삭제와 전체 opt-out을 할 수 있다. 삭제된 record는 다음 요청에서 제외되고 별도 복사본으로 남지 않는다.
5. **동의 증거·동기화**: 계정 정본은 정책 버전, server 기준 동의 시각, 철회 시각, 현재 enabled 상태를 표현한다. 새 기기·재설치에서 계정 상태를 복원하고 로그아웃·계정 전환 때 로컬 cache를 지운다. 키 없음·손상·버전 불일치는 OFF다.
6. **철회 효력**: 철회 시작 시 서버는 OFF와 새 consent generation을 원자 저장해 신규 외부 전송 lease를 차단하고 진행 중 결과를 폐기한다. 기존 lease가 모두 해제된 것을 확인한 뒤에만 철회 완료를 응답하며, timeout·장애·해제 불확실 상태는 완료로 고지하지 않는다. 따라서 철회 완료 응답 뒤 과거 기록의 신규 LLM 전송은 0건이어야 한다. 철회 전에 외부 processor가 이미 처리한 데이터의 실제 잔존 여부와 삭제 절차는 provider 계약·로그 설정으로 확인해 처리방침 시행 전에 고지하며, 확인 전 `모두 즉시 삭제`라고 단정하지 않는다.
7. **인증·접근**: Supabase bearer token을 서버가 검증해 얻은 identity만 사용하고 client `user_id`는 신뢰하지 않는다. owner 조건과 RLS를 서버에서 다시 강제하며 private 기록의 존재·개수·오류 차이를 다른 계정에 노출하지 않는다.
8. **분석 분리**: 개인화 opt-in만으로 PostHog 이벤트를 켜지 않는다. 별도 분석 동의가 있을 때도 원문·source/record ID·정확한 책/날짜·민감 주제 없이 [analytics.md §3.1.5](./analytics.md#315-개인화-context-이벤트-allowlist-1309-목표)의 allowlist만 보낸다.
9. **출시 게이트**: DEV의 합성 구현·검증은 가능하지만 #1373의 personalization OFF/ON UAT 인수, 실제 처리위탁/국외이전 문구 확인, 동의·철회·RLS·삭제 회귀 검증 전에는 Production에 기능·동의 UI·실사용자 전송을 열지 않는다.

## 1. 수집하는 개인정보 항목

| 구분 | 항목 |
|---|---|
| 계정(로그인 시) | 이메일, 표시이름·닉네임, 프로필 이미지(Google 제공) |
| 서비스 이용 | 독서 기록(책·쪽수·세션·스트릭·XP), 한 문장·감상, 짹(좋아요), 둥지/완독 |
| 문의 | 문의 내용, 회신용 이메일, 앱 버전 |
| 행동 데이터(분석) | 페이지뷰·클릭·이벤트(PostHog `distinct_id` 및 동의 구성에 따라 브라우저·계정 활동과 연결될 수 있음) / **세션 리플레이**(별도 선택 동의 대상) |
| 자동 생성 | 쿠키·기기/브라우저 정보, 접속 로그 |

- 게스트(비로그인)는 계정정보 없이 **로컬(localStorage)**로만 동작. 로그인 시 Supabase로 적재.

## 2. 수집·이용 목적

서비스 제공(독서 기록·소셜·현행 둥지), 본인 식별·인증, 문의 응대, **서비스 개선·통계 분석**, 별도 선택 동의 시 세션 리플레이로 사용성 개선·LLM 독서 파트너 품질 향상. 분석 데이터를 일률적으로 익명이라고 단정하지 않으며 식별자·보유·삭제 범위는 실제 PostHog 구성과 동의 상태를 따른다.

## 3. 보유·이용 기간

회원 탈퇴 또는 동의 철회 시까지를 원칙으로 하되, 법령상 보존 의무가 있으면 해당 기간을 별도로 고지한다. 행동 분석 데이터의 실제 PostHog 보존기간, 철회·탈퇴 후 삭제 또는 비식별 처리, 문의·모더레이션 감사로그 보존기간은 현재 **미검증**이며 게시 전 확정해야 한다. 미동의 항목은 향후 수집하지 않아야 하고 그 동작을 DEV·Production에서 검증한다.

## 4. 제3자 처리위탁 및 국외 이전

서비스 운영을 위해 아래에 처리를 위탁하며, 일부는 **국외**로 이전된다(PIPA 고지).

| 수탁사 | 처리 항목 | 목적 | 이전 국가 |
|---|---|---|---|
| Supabase | 계정·독서기록·문의 | DB·인증 호스팅 | 국내(대한민국, AWS 서울 `ap-northeast-2` — 2026-07-02 Management API 실측, #1126) |
| PostHog | 행동 이벤트 / 리플레이(선택) | 분석·세션 리플레이 | 미국 |
| Google | 이메일·프로필 | OAuth 로그인 | 미국 |
| Upstage | 책 사진·한 문장 텍스트 | OCR·LLM 독서 파트너 | 국내(한국) |

- 이전 일시·방법: 서비스 이용 시점에 네트워크 전송. 외부 판매·광고 목적 제공 없음.

## 5. 이용자의 권리

열람·정정·삭제·처리정지·동의철회를 언제든 요구할 수 있다. 행사 방법:

- 앱 **서재(내 서재) → 데이터 내보내기**(JSON)로 열람(#568 이후 내보내기는 설정→서재로 이동 · 드리프트 정정 2026-07-09), **설정 → 동의 토글**로 선택 항목 철회를 요청한다. 향후 전송 중단, PostHog identity reset, 기존 데이터 처리까지 실제로 완료되는지는 구현·Production 검증 전까지 보장하지 않는다.
- 계정·데이터 삭제, 기타 요청: 아래 연락처.

## 6. 쿠키

서비스는 분석을 위한 **first-party 쿠키**(PostHog distinct_id)를 사용한다. 브라우저 설정으로 차단 가능하나 일부 통계가 수집되지 않을 수 있다. 별도 광고·추적 제3자 쿠키는 사용하지 않는다.

## 7. 개인정보 보호책임자 / 연락처

문의·권리 행사: **`readinggo.admin@gmail.com`** (앱 설정 → 운영자에게 문의).

저작권 권리자 삭제요청도 현재는 이 일반 문의 채널로 접수한다. 관리자는 대상 문장을 확인해 필요한 경우 수동 비공개 또는 삭제하고 처리 결과를 필요한 범위에서 기록한다. 전용 신고 폼·상태 전이·이의 절차·자동 전 표면 검증은 반복 요청, 공개량·영리성 증가, 수동 처리 누락이 실제로 나타날 때 #1463에서 재검토한다. 이 후순위 작업은 공개 1,000자와 일반 DEV·Production 배포를 차단하지 않는다.
