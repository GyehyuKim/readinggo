# 개인정보처리방침 (Privacy Policy) — 정본 + 게시 설계

> **신설 (#757, 2026-06-17)**: ReadingGo는 이메일(Google OAuth)·독서기록·행동데이터를 수집하므로 PIPA상 처리방침 게시가 의무. 동의 모델은 [analytics.md §5](./analytics.md), 측정 이벤트는 §3.1.
> **v17 전환 주의 (2026-08-19, #1452·#1454·#1456)**: 이 문서는 현재 배포된 서비스의 처리 사실을 설명한다. 책나무·친구 공개범위·XP 동결은 승인된 목표 계약이지만 아직 배포되지 않았으므로 현행 문구를 조용히 미래형으로 바꾸지 않는다. 아래 §0의 고지·동의·권한 migration과 실제 Production 검증 후 시행일을 갱신한다.
> **편집 정책**: 처리방침 본문 변경은 이 파일 PR로. spec-only 준수. 코드(링크·화면 배선)는 후속.
> **주의**: 아래는 운영용 정본 초안이다. 정식 런칭·대규모면 법무 검토 권장(작성자는 변호사 아님). 시행일·수탁사 리전은 게시 전 확정.

## 0. 책나무 전환 개인정보 계약 (배포 전 게이트)

1. 친구 책나무에서 공개할 수 있는 정보는 책 메타데이터와 `읽는 중|완독|중단|관심` 상태로 제한한다. 진도, 별점, 후기, 개인 감상, AI 대화는 별도 결정 없이 추가하지 않는다.
2. 문장 본문은 기존 `public|followers|private` 설정과 서버 권한을 따른다. 비공개 문장의 존재·개수·내용과 `my_note`는 친구 화면·집계·분석에 포함하지 않는다.
3. **4-B 결정**: 기존 사용자는 변경 항목·공개 대상·효력일·거부·탈퇴·되돌리기 방법을 사전 고지한 뒤 친구 책나무를 자동 활성화한다. 사용자는 효력일 전후 언제든 전체 opt-out할 수 있고, opt-out은 모든 기기에서 복원되며 재활성화는 사용자의 명시적 선택으로만 가능하다.
4. **5-A 결정**: 현행 `user_books`·`wish_books` base table 직접 읽기는 친구 공개 계약의 권한 경계가 아니다. 서버가 상호 팔로우·차단·opt-out을 판정하는 제한 view/RPC를 먼저 배포하고 신규 클라이언트를 전환한다. 승인 버전 수신과 구버전 호출량을 관측해 최소 지원 버전을 적용한 뒤에만 base RLS를 `owner-only`로 축소한다.
5. XP·둥지·성·하루 만회 전용 데이터는 신규 앱에서 사용하지 않으며 구 APK 호환 목적으로 유지하지 않는다. Production 물리 삭제 전 rollback용 백업의 항목·목적·보유 기간·파기 시점을 migration 승인 기록과 처리방침·데이터 내보내기에 반영한다.
6. 처리방침 시행일·앱 내 사전 고지·opt-out 저장/복원·제한 API의 역할별 회귀 테스트·Production 직접 조회 검증이 끝나기 전에는 친구 책나무를 자동 활성화하지 않는다. base RLS 축소는 4항의 구버전 관측과 최소 지원 버전 게이트를 별도로 통과해야 한다.
7. 전환 상태는 최소한 고지 버전·고지 시각·효력일·opt-out 시각·재활성화 시각·기기 간 복원 여부를 판정할 수 있어야 한다. 정확한 저장 컬럼·enum·API 이름은 개인정보 검토와 구현 계획 전까지 미결정이다.
8. 분석 동의 철회 시 향후 이벤트·리플레이 전송 중단뿐 아니라 PostHog identity reset과 기존 이벤트의 삭제 또는 비식별 처리 여부를 결정·검증한다. 현재 처리 범위는 미검증이다.
9. 계정 삭제가 Supabase 데이터만 지우는지, PostHog·문의·모더레이션 감사로그까지 처리하는지와 각 보존기간을 시스템별로 명시한다. 법적 보존과 사용자 삭제의 경계는 승인 전 미결정이다.

## 1. 수집하는 개인정보 항목

| 구분 | 항목 |
|---|---|
| 계정(로그인 시) | 이메일, 표시이름·닉네임, 프로필 이미지(Google 제공) |
| 서비스 이용 | 독서 기록(책·쪽수·세션·스트릭·XP), 한 문장·감상, 짹(좋아요), 둥지/완독 |
| 문의 | 문의 내용, 회신용 이메일, 앱 버전 |
| 행동 데이터(분석) | 페이지뷰·클릭·이벤트(PostHog `distinct_id` 및 동의 구성에 따라 브라우저·계정 활동과 연결될 수 있음) / **세션 리플레이**(별도 선택 동의 대상) |
| 자동 생성 | 쿠키·기기/브라우저 정보, 접속 로그 |

- 게스트(비로그인)는 계정정보 없이 **로컬(localStorage)**로만 동작. 로그인 시 Supabase로 적재.

## 2. 수집·이용 목적

서비스 제공(독서 기록·소셜·현행 둥지), 본인 식별·인증, 문의 응대, **서비스 개선·통계 분석**, 별도 선택 동의 시 세션 리플레이로 사용성 개선·LLM 독서 파트너 품질 향상. 분석 데이터를 일률적으로 익명이라고 단정하지 않으며 식별자·보유·삭제 범위는 실제 PostHog 구성과 동의 상태를 따른다.

## 3. 보유·이용 기간

회원 탈퇴 또는 동의 철회 시까지를 원칙으로 하되, 법령상 보존 의무가 있으면 해당 기간을 별도로 고지한다. 행동 분석 데이터의 실제 PostHog 보존기간, 철회·탈퇴 후 삭제 또는 비식별 처리, 문의·모더레이션 감사로그 보존기간은 현재 **미검증**이며 게시 전 확정해야 한다. 미동의 항목은 향후 수집하지 않아야 하고 그 동작을 DEV·Production에서 검증한다.

## 4. 제3자 처리위탁 및 국외 이전

서비스 운영을 위해 아래에 처리를 위탁하며, 일부는 **국외**로 이전된다(PIPA 고지).

| 수탁사 | 처리 항목 | 목적 | 이전 국가 |
|---|---|---|---|
| Supabase | 계정·독서기록·문의 | DB·인증 호스팅 | 국내(대한민국, AWS 서울 `ap-northeast-2` — 2026-07-02 Management API 실측, #1126) |
| PostHog | 행동 이벤트 / 리플레이(선택) | 분석·세션 리플레이 | 미국 |
| Google | 이메일·프로필 | OAuth 로그인 | 미국 |
| Upstage | 책 사진·한 문장 텍스트 | OCR·LLM 독서 파트너 | 국내(한국) |

- 이전 일시·방법: 서비스 이용 시점에 네트워크 전송. 외부 판매·광고 목적 제공 없음.

## 5. 이용자의 권리

열람·정정·삭제·처리정지·동의철회를 언제든 요구할 수 있다. 행사 방법:

- 앱 **서재(내 서재) → 데이터 내보내기**(JSON)로 열람(#568 이후 내보내기는 설정→서재로 이동 · 드리프트 정정 2026-07-09), **설정 → 동의 토글**로 선택 항목 철회를 요청한다. 향후 전송 중단, PostHog identity reset, 기존 데이터 처리까지 실제로 완료되는지는 구현·Production 검증 전까지 보장하지 않는다.
- 계정·데이터 삭제, 기타 요청: 아래 연락처.

## 6. 쿠키

서비스는 분석을 위한 **first-party 쿠키**(PostHog distinct_id)를 사용한다. 브라우저 설정으로 차단 가능하나 일부 통계가 수집되지 않을 수 있다. 별도 광고·추적 제3자 쿠키는 사용하지 않는다.

## 7. 개인정보 보호책임자 / 연락처

문의·권리 행사: **`readinggo.admin@gmail.com`** (앱 설정 → 운영자에게 문의).

저작권 권리자 삭제요청도 현재는 이 일반 문의 채널로 접수한다. 관리자는 대상 문장을 확인해 필요한 경우 수동 비공개 또는 삭제하고 처리 결과를 필요한 범위에서 기록한다. 전용 신고 폼·상태 전이·이의 절차·자동 전 표면 검증은 반복 요청, 공개량·영리성 증가, 수동 처리 누락이 실제로 나타날 때 #1463에서 재검토한다. 이 후순위 작업은 공개 1,000자와 일반 DEV·Production 배포를 차단하지 않는다.
