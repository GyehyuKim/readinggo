# #1389 재키 활성 표면 감사표

> 감사 기준: `origin/main@498b6e2`에서 시작한 로컬 구현. 후보 A/B/C는 DEV 비교 전용이며 사람의 선택 전에는 어떤 정본 자산도 교체하지 않는다. 이름은 `Jacky / 재키`를 유지한다.

| 활성 표면 | 현재 자산/구현 | 동일 캐릭터 여부 | 이번 변경 | 선택 전 남은 불일치·수동 결정 |
|---|---|---:|---|---|
| 앱 아이콘 | `assets/icon.png`, 네이티브 generated icon | 부분 | 교체 안 함 | 래스터 아이콘이 기존 통통한 SparrowMark이며 새 후보의 약 2.5등신 전신과 아직 미대조. 후보 선택 뒤 원본·iOS·Android 전 사이즈 재생성 필요 |
| 헤더 | `SparrowMark` (`js/icons.js`) | 기준선 | 교체 안 함 | 기존 고개 든 통통 실루엣은 성인형 2.5등신 모델이 아님. 선택 후보의 24px 얼굴/마크 파생형을 별도 승인해야 함 |
| 로딩 | `BootSplash`의 `SparrowMark` | 기준선 | 교체 안 함 | 헤더와 같지만 40px에서 후보 전신/얼굴 중 어느 파생형을 쓸지 수동 결정 필요 |
| 로그인 | `SparrowMark spark` | 기준선 | 교체 안 함 | 골드 spark가 새 모델 시트 기본형에는 없음. 유지/제거는 후보 선택 뒤 브랜드 모먼트 규칙으로 결정 필요 |
| 재키 대화 | 별도 임시 새 SVG | **불일치** | 별도 새 SVG를 제거하고 canonical `SparrowMark`로 통일 | 현행 기준선과는 일치. 최종 후보 선택 뒤 대화용 얼굴 파생형 교체 필요 |
| 공유 카드 | `share-card.js`에 SparrowMark path 복제 | 부분 | 교체 안 함 | 인라인 path 복제로 정본 드리프트 위험. 후보 선택 뒤 공용 생성 함수/승인된 path로 통합 필요 |
| 스토어 자산 | `store/`, `assets/`, generated screenshots/icons | 미검증 | 교체 안 함 | 스토어 초안은 제출 금지 상태이며 기존 아이콘/스크린샷 provenance와 후보를 실제 콘솔 규격별 수동 검수해야 함 |
| 사용자 fallback | 여러 피드·프로필에서 `SparrowMark` | **정체성 혼동** | generic `user` 모노라인 아이콘으로 교체 | 사용자와 재키가 분리됨. 실제 `avatar_url` 렌더 범위는 별도 제품 개선 가능 |

## 후보 검토 경계

- DEV 합성 검수 모드 상단의 **재키 A/B/C 비교**로만 연다.
- 후보마다 모델 시트 크기와 48px를 같은 조건으로 비교하고 7개 기준을 `PASS`/`FAIL`로 기록한다.
- 하나라도 `FAIL`이면 해당 후보는 탈락이다. 모두 실패하면 brief를 수정하며 임시 정본을 만들지 않는다.
- Production 빌드에는 비교 UI, 후보 SVG, 후보 카피가 포함되지 않는다.
